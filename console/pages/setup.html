Setup

Plug the flight controller into this laptop by USB (props off). Everything a computer can do here is a button, usually with a picture of what the drone should be doing, and the drone answers through "FC says". Do the steps in order. Each one assumes the ones above it.

-

Your drone & connection

Leave this on Automatic. Cable plugged in means bench: the console uses the cable and the one-click tools borrow it. Cable out means Bluetooth, which Operations uses in the field. No pairing is needed; the bridge finds the drone as soon as it has power. A mission is refused while a cable is plugged in. Radio is only for boards without Bluetooth.

MODE 2 BETA

Set up a freshly built drone

Component checklist first, then the same flight setup. New, and not yet tested end to end on a real build.

BETA. The fresh-build path is new. The Betaflight conversion has been flown, but the wiring, UART, receiver and ESC steps here have only been checked in the simulator. Follow them with care, keep the props off until the bench arm test, and tell us what was wrong or missing. Contributions through the project's GitHub repository are welcome.

Components

Essential
  • Frame, 4 motors, 4-in-1 ESC 5" 6S; must carry 0.5 kg extra
  • Flight controller in ArduPilot's list type its name in the board box at the top: the list shows every supported board
  • GPS with compass position + heading
  • RC transmitter + receiver your override, always wins
  • Bluetooth in the FC or a telemetry radio to start missions from the laptop
  • Dropper (3D print) + standard MG90S positional, never 360°
  • Extinguisher ball ≤ 0.5 kg, 6S battery + charger, strap
Optional
  • FPV camera + VTX + goggles only for manual flying out of sight
  • Buzzer / LEDs
Build it, plug in USB only, then continue from the firmware step.
