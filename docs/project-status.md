# Project status and parts

## Done

- Simulation: the full mission (fly to a pin, drop, return) proven in
  ArduPilot SITL.
- Conversion: Betaflight backup, ArduCopter flashed over USB, base parameters,
  radio and accelerometer calibration. The Setup page does all of this now.
- First flights: maiden in Stabilize, Loiter shakedown, Bluetooth link from
  the laptop.

## Next

- Dropper: fit a standard (positional) MG90S. The first one fitted turned out
  to be a 360° type, which cannot hold a pin. Dummy-ball release tests.
- Full rehearsal: dummy ball on a target, then a real ball on a controlled
  test fire.
- Site service: place the real factories on the Operations map and fly them.

## Parts beyond a normal 5" quad

| Item | Note |
|---|---|
| MG90S metal-gear 9 g servo, standard (positional) | pulls the release pin, FC output 6 |
| Extinguisher ball, 0.5 kg class (AFO mini or similar) | the 1.3 kg standard ball is too heavy for a 5" |
| Bluetooth module built into the SpeedyBee F405 V5 | how the laptop starts a mission |
